## Featured Project

### [StunntingApp — Android Stunting Screening](https://github.com/FauzanRAY-STAR/StunntingApp)

![Platform](https://img.shields.io/badge/Platform-Android-3DDC84?style=for-the-badge&logo=android&logoColor=white)
![Stack](https://img.shields.io/badge/Stack-Kotlin_·_CameraX_·_MediaPipe_·_Room-0F4C81?style=for-the-badge)
![Focus](https://img.shields.io/badge/Focus-Computer_Vision_·_Health--Tech-00A6A6?style=for-the-badge)

> An Android application for stunting screening in children aged 24–59 months. It estimates height from smartphone camera input and calculates a height-for-age z-score for screening support.

- **Markerless estimation:** processes pose landmarks without attaching physical markers
- **Real-time camera:** captures and analyzes frames using CameraX
- **Pose processing:** detects body landmarks with MediaPipe Pose Landmarker
- **Local history:** stores measurement records using Room Database
- **App architecture:** uses Kotlin, ViewModel, Navigation Component, and Hilt

## 🚀 Featured Project

### [StunntingApp](https://github.com/FauzanRAY-STAR/StunntingApp)

An Android application for stunting screening in children aged 24–59 months. It estimates height from smartphone camera input using MediaPipe Pose Landmarker and pixel-to-centimeter conversion, then calculates a height-for-age z-score for screening support.

- Markerless height estimation using computer vision
- Real-time camera flow with CameraX
- Pose landmark processing with MediaPipe
- Local measurement history using Room Database
- Kotlin architecture with ViewModel, Navigation Component, and Hilt

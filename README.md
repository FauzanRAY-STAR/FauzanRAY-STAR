### Featured Project

#### [StunntingApp](https://github.com/FauzanRAY-STAR/StunntingApp)

Android application for stunting screening in children aged 24-59 months. The app estimates height using smartphone camera input, MediaPipe Pose Landmarker, and pixel-to-centimeter conversion, then calculates height-for-age z-score for screening support.

**Highlights**
- Markerless height estimation using computer vision
- Real-time camera flow with CameraX
- Pose landmark processing with MediaPipe
- Local measurement history using Room Database
- Android architecture using Kotlin, ViewModel, Navigation Component, and Hilt
